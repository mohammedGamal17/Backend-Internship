Library Management System

Build a console application to manage books, members, and loans using SQL Server and LINQ.

C# · SQL Server · LINQ

1. Objective

Build a console application for a library management system that interacts with a SQL Server database. The application should allow users to manage books, members, and loans, and perform various operations such as searching, filtering, sorting, and viewing reports using LINQ.

2. Requirements

  • Connect to the provided SQL Server database.
  • Implement core features for managing books, members, and loans.
  • Use LINQ for data processing and querying where appropriate.
  • Handle user input and provide a clear and user-friendly console interface.
  • Ensure the application is organized, maintainable, and follows good coding practices.

3. Database

You are provided with a SQL file that contains a pre-built database with sample data. Follow the instructions in the file to set up the database on your local SQL Server instance.

Note Make sure to run the SQL file using SQL Server Management Studio (SSMS) and verify that the database and data are created successfully before connecting your application.

4. What You’ll Build

A console application with a menu-driven interface that provides functionalities to manage the library system. You can design the UI and features in a way that suits your approach and style.

6. Key Features

  • Manage books (add, update, delete, view).
  • Manage members (add, update, delete, view).
  • Handle book loans and returns.
  • Search, filter and sort data (e.g., by title, author, category, member).
  • View lists with pagination (optional).
  • Show relevant reports (e.g., most borrowed books, overdue loans, etc.).

7. Additional Notes

  • You are free to design your own menu structure and user experience.
  • The application should handle invalid input and edge cases (e.g., no results, duplicate entries, etc.).
  • Focus on clean code, proper separation of concerns, and meaningful method names.
  • Feel free to add any extra features you think are useful or interesting.
